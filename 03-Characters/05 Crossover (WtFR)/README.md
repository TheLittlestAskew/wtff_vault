# Crossover — Where the Flowers Remember (WtFR)

**Where the Flowers Remember** is a separate, full campaign (DM **Alec**) running in parallel to *Where the Flowers Forget* (this vault, DM **Adam**). The two stories occasionally cross over.

This folder holds **crossover stubs only** — WtFR characters/NPCs the WtFF party has actually encountered, recorded from the **WtFF point of view**. These are intentionally lightweight: a line on who they are and where WtFF met them, plus backlinks to the relevant WtFF session(s).

**Do not** build these into full character sheets or write WtFR-internal lore here. We only know what the WtFF party witnessed. See `Workflows/Project/_Campaign_Setup.md` → "Campaign structure".

- **PCs (Alec's party):** Lute, Nyx, Rowan, Auroran, Kidu, Dolm
- **NPC:** Margaret "Mags" Honeythatch (their recruiter)
